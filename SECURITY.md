# Security Policy

## Supported versions

MotionVideo is a hosted site. Production is continuously deployed from `main`, so security fixes land there; there are no supported release branches.

## Reporting a vulnerability

Please report vulnerabilities privately through [GitHub Security Advisories](https://github.com/motionvideohq/motionvideo.xyz/security/advisories/new). Do not open a public issue.

Include:

- What you found and why it matters
- Steps to reproduce or a proof of concept
- The affected URL, commit, or deployment
- Any suggested fix

We will investigate legitimate reports and do our best to fix confirmed problems quickly. Please give us reasonable time to ship a fix before sharing details publicly.
