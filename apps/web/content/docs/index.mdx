---

MotionVideo is a gallery of motion videos made by AI agents, each shown with the prompt behind it. Around the gallery:

- **Gallery**: motion videos by category, with their prompts. Free, with or without a plan.
- **Moves**: named motion design techniques your agent understands. Every move's copy-ready prompt is in Pro.
- **Templates**: tested prompt structures with fill-in fields. Every template's full prompt and the customizer are in Pro.
- **Agent skill**: skills that teach your coding agent motion design, rendered from code with Remotion, HyperFrames, Editframe or fframes. Included in Pro and Business.
- **MCP server**: the catalog in any MCP client.
- **Public API**: read-only JSON of the catalog, the directories and the public part of every move.

## Set up with your agent

Paste this line into your coding agent:

```text title="Prompt"
Read https://motionvideo.xyz/skill.md and set up MotionVideo for me.
```

The [skill.md](/skill.md) file tells the agent how to connect the MCP server, search the gallery, pull prompts and find moves.
